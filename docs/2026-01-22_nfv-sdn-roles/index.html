NFVとSDNの役割分担：「仮想化」と「制御」の最強コンビ

  • #NFV
  • #SDN
  • #仮想化
  • #ネットワーク
  • #ITパスポート

ネットワーク技術の分野で頻出の「NFV」と「SDN」。どちらもネットワークを柔軟にする技術ですが、担当領域が異なります。

一言で言えば、「NFVは部品を作る技術」であり、「SDNはその部品を動かす技術」です。この記事では、この2つがどのように連携して次世代のインフラを支えているのかを図解で解説します。

1. 用語の全体像と役割分担

まずは、両者の役割を一言で定義します。

📦 NFV Network Functions Virtualization

専用機器（ルータ等）をソフトウェア化して、汎用サーバ上で「作る」技術。

キーワード：機能の仮想化
🎮 SDN Software Defined Networking

作られた機能同士の通信経路や動作を、ソフトウェアで集中「制御」する技術。

キーワード：集中制御

2. 全体構成の図解（連携イメージ）

NFVで「仮想的なネットワーク機器（VNF）」を作り、SDNコントローラがそれらを指揮してネットワーク全体を動かします。

SDN (制御)
SDNコントローラ

「AからBへ通信せよ」「ここは遮断せよ」と指示

NFV (仮想化)
VNF 1 Firewall
VNF 2 Router
VNF 3 Load Balancer
汎用サーバ (IAサーバ)

用語の整理

  • NFV： ネットワーク機能を仮想化する「技術全体」のこと。
  • VNF： NFVによって作られた「個々の仮想機能（仮想ルータなど）」のこと。

3. なぜ組み合わせるのか？

NFVだけでも「高価な専用機器を買わなくて済む」というメリットはあります。しかし、仮想化されたルータやファイアウォールがバラバラに動いているだけでは、管理の手間は変わりません。

そこでSDNの出番です。SDNを組み合わせることで、「VNFの立ち上げ（NFV）」から「通信経路の設定（SDN）」までを全自動化できるようになります。これにより、柔軟でスケーラブルなネットワークが完成します。

4. 試験対策：SDNとNFVの違い

ITパスポートや基本情報技術者試験では、説明文がどちらを指しているかを問われます。

項目 NFV SDN
主目的 機能の仮想化（脱・専用機器） ネットワークの集中制御
対象 ルータ、FW、ロードバランサ等 通信経路、トラフィック、スイッチ
成果物 VNF（仮想化された機能） 制御ルール、ポリシー

まとめ

試験で迷ったら、以下のフレーズで判別してください。

  • 「専用機器を不要にする」「仮想化する」 とあれば → NFV
  • 「ソフトウェアで制御する」「集中管理する」 とあれば → SDN

「NFVで作って、SDNで操る」。この役割分担さえ押さえておけば、複雑なネットワーク用語も怖くありません。
